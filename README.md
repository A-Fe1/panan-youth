# 🍀 磐城遇见

面向磐安青年的公益交友联谊网页平台。手机扫码/点链接即用，无需下载 APP。

## 功能一览

- **注册登录**：手机号 + 密码注册，密保问题找回身份（管理员重置密码）
- **资料卡**：性别（勾选）、年龄、哪里人、工作属地、证件照、生活照（3张）、
  我想分享的照片（6张）、兴趣爱好（➕动态标签，可一直添加）、MBTI、星座、自我介绍、微信号
- **兴趣匹配**：按共同爱好数量排序推荐同频青年
- **双向交友**：打招呼 → 对方回应 → 成为朋友 → 互相解锁微信号；婉拒则什么都不泄露
- **安全防护**：每日打招呼限额、举报、管理后台封禁、密码/密保哈希加密存储、隐私政策
- **管理后台**：数据统计、用户管理（封禁/重置密码）、举报处理

## 运行模式

| 模式 | 进入方式 | 说明 |
|------|---------|------|
| 本地演示模式 | 直接双击 `index.html` | 数据仅存当前浏览器，演示账号 `13800000001/2/3`，密码 `123456`，管理密码 `admin888` |
| 正式模式 | 配置 `js/config.js` 后部署 | GitHub Pages（网页）+ Supabase 免费版（数据库） |

## 技术要点

- 纯原生 HTML/CSS/JS 单页应用（hash 路由），无构建工具，无框架依赖
- 数据库行级安全（RLS）：微信号仅在双向成为朋友后可读；密码/密保 PBKDF2 哈希；
  手机号在密保表中仅存加盐慢哈希，防枚举
- 照片上传前本地自动压缩（1080px / 75% 质量），节省免费存储额度
